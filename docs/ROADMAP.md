## Planned next: v0.5.0 — Easier setup and updates

The aim is to make the game straightforward to install and keep up to date:

- Install through one Windows setup program, then start Sightline from its installed game shortcut or executable.
- Choose your own compatible ROM where it already lives. There should be no need to move it into a special folder.
- Start with a **pure Original** setup, with GPU enhancements and sprint off, or choose available enhancements during setup. Change these choices later in the game.
- Prepare optional Community HD or XBLA visual styles through the graphical setup flow. Community HD comes from its maintainers; XBLA requires your own remaster source. Players should not need a source checkout, scripts, or command-line tools.
- Optionally check for updates at startup and install a newer release from within Sightline.

Sightline will still ship without a ROM, XBLA source archive, or converted game artwork. The installer will guide players who have the required files or choose to fetch the optional Community HD pack.

This version is **planned**, not released. There is no announced date. Follow the [player roadmap](https://github.com/users/mscrnt/projects/9) for updates.

Other ideas are not scheduled release promises unless they appear on that roadmap. For the current download and setup instructions, see the [README](../readme.md).
