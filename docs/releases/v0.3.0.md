# Sightline v0.3.0 — Visual Fidelity

**Date:** 2026-10-16
**What it is:** the v0.3.0 Visual Fidelity line (`sightline/xbla-world-assets`,
with the World Detail and texture-provider rounds before it) integrated into
the canonical `master` and released as a Windows binary,
`Sightline-v0.3.0-win32.zip`. Everything new here changes how the game is
drawn, never how it plays: the simulation, its tick and its traces are the
game's own in every setting, and every new setting defaults to the accepted
v0.2.0 rendering.

## What is in it

### PRESENTATION: ORIGINAL, COMMUNITY HD, XBLA

One setting chooses how the game looks, and it moves every visual provider
together (D-022): the texture provider and the world-asset provider resolve
the same choice, so mixed states such as cartridge artwork under a remastered
sky cannot be selected.

| value | what it draws | what it needs |
|---|---|---|
| **ORIGINAL** (default) | the cartridge's own textures and models, read from the ROM | nothing more |
| **COMMUNITY HD** | the Community HD texture pack where it covers a texture (D-020) | the pack, fetched by `Get-Textures.cmd` in the package |
| **XBLA** | the Xbox 360 remaster's textures and world assets: backgrounds, skies, characters, props and first-person models (D-021) | a pack and world assets prepared from your own ROM and your own copy of the remaster's archive |

- **Switching:** F5, or View / Create on a controller, cycles ORIGINAL →
  COMMUNITY HD → XBLA in a level; the front end has it under **OPTIONS →
  SETTINGS → DISPLAY → PRESENTATION**, and the watch under **SIGHTLINE →
  GRAPHICS**. One stored value, shared by all three.
- **COMMUNITY HD in the package:** `Get-Textures.cmd` downloads the pinned
  official release of the Community HD project from its maintainers, checks
  it against the size and SHA-256 recorded in `tools\community-source.json`,
  and converts it into `%LOCALAPPDATA%\sightline\assets\texpacks`. Sightline
  redistributes no part of it. The pack is the GoldenEye 007 HD texture pack,
  created by intermissionfb with font textures by GhostlyDark
  ([github.com/GhostlyDark/GoldenEye-007-HD](https://github.com/GhostlyDark/GoldenEye-007-HD)).
- **XBLA across the campaign:** all 20 campaign missions — 19 stage
  backgrounds and 7 skydomes, with the stages that carry no dome of their own
  borrowing or being lent one — plus characters, props and the first-person
  models. Preparation is a source-checkout step
  ([docs/xbla-setup.md](../xbla-setup.md)): `tools\windows\prepare-all.ps1`
  prepares the texture packs and every XBLA stage in one command, and
  `prepare-xbla-assets.ps1 -All` reads its plan from the runtime's own
  tables. The game reads prepared sets from `%LOCALAPPDATA%\sightline\assets\`
  when no override is set, so a package install can use sets prepared there
  (`-TexturesOut` / `-WorldOut`). The XBLA set is user-supplied: no tool here
  obtains the remaster.
- **Where the remaster and the game disagree,** the difference is recorded as
  a numbered divergence in [docs/divergences.md](../divergences.md)
  (D-023 – D-056: the Dam's generated zenith clouds, fog ranges and
  atmosphere rows per stage, lent and borrowed domes, decal and door
  corrections, the Aztec shuttle drawn from its original generation, the
  Egyptian crypt doors, and the rest). Each one applies only under
  PRESENTATION XBLA.

### WORLD DETAIL: ORIGINAL / ENHANCED (D-019)

ENHANCED stops the near-fog visibility-range test from withholding props and
characters at the render seam, so they stay drawn until the far-fog cull or
the room / portal set removes them. Render only: the simulation's own copy of
the test is untouched. Default ORIGINAL.

### FRAME RATE and SHOW FPS

- **FRAME RATE** (DISPLAY tab and the watch's DISPLAY page): ORIGINAL
  (default), 30, 60, 120, 144, 165, 240, UNLIMITED. Above the game's own
  rate, extra frames are presented between game frames by re-walking the
  frame's display list with a blended camera
  ([docs/decisions/high-refresh-presentation.md](../decisions/high-refresh-presentation.md)).
  The simulation stays at the game's own rate, and per-tick traces are
  byte-identical with and without it. With VSync on, a 60 Hz display leaves
  no room for an extra frame.
- **SHOW FPS** draws a presented-frames-per-second counter in the corner.

### Fixes and rendering

- **The model-code crashes when shooting guards (B-CRASH1).** A collision
  point's related number was left byte-swapped in the native model swap, so
  the game's blood-stain code painted one byte at a time into the top bytes
  of Model pointers. Fixed at the swap. ORIGINAL failed identically before
  it, so this is a native-port defect, not a presentation one. A crash report
  now names the Model a model-code fault followed, and its owner.
- **Dynamic doors (D-027).** A door the game reshapes as it moves (the Dam's
  yard gates, the roller door, the gas-plant doors) is drawn at the game's
  own live box in every presentation. `SL_DYNDOOR=0` draws doors as the
  cartridge does.
- **Destroyed objects are kept (D-028).** The native destroyed-object vertex
  store is eight times the cartridge's, so the game's low-memory free of an
  off-screen destroyed object is not reached in play. `SL_DESTROYED_KEEP=0`
  sizes the store as the cartridge does.
- **Renderer performance (#88).** Two exact repairs to the world-asset
  fill under XBLA (the open-hole answers are remembered, and the fill grid's
  box test runs four candidates at a time in SSE2); frames before and after
  hash identically.

## Nothing ROM-derived ships

As in v0.2.0, the executable carries Sightline's own code and permitted
runtime material only. Game data, the Community HD pack and the remaster's
assets are read or prepared on the player's machine and never shipped; the
package validator scans every shipped file against ROM-derived excerpts with
the ROM given.

  the package carries no XBLA tooling.
- Not in this release: Modern Lighting.

## ROM requirement

Sightline includes no GoldenEye ROM and no game data. A user-supplied
GoldenEye 007 (USA) dump is required: a plain, uncompressed, big-endian
`.z64`, 12582912 bytes, SHA-1 `abe01e4aeb033b6c0836819f549c791b26cfde83`.
`.n64` / `.v64` dumps are byte-swapped and are refused at start-up with the
reason on the console.

## Windows support statement

Windows 10 / 11 x64, 32-bit build, OpenGL. No other platform.
