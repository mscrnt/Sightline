# Sightline v0.2.0 — QoL Phase 1 (first Windows binary release)

**Date:** 2026-09-21
**What it is:** the QoL Phase 1 line (`sightline/qol-controls`) integrated
into the canonical `master` and released as **the first distributable Windows
binary**, `Sightline-v0.2.0-win32.zip`. v0.1.0 was a source-only checkpoint
(see `docs/releases/v0.1.0.md` for why); this is the first release a player
can download and run.

## What is in it — QoL Phase 1, as accepted

Everything below shipped on the QoL line and was accepted by the owner on the
native build; nothing here is a parity claim against the cartridge.

**Controls**

- Semantic keyboard / mouse / controller controls: physical inputs bind to
  game actions (fire, aim, reload / use, weapon cycle, zoom, crouch, sprint,
  the watch, …) rather than to N64 pad positions, with **persistent
  remapping** in the native settings.
- Modern controller layouts and presentation: Xbox and DualSense models with
  layout presets (DEFAULT, SOUTHPAW, GREEN THUMB), the controller page
  showing what each physical control does; a control bound to nothing reads
  **UNBOUND** (Y / TRIANGLE is shown that way rather than hidden).
- The bumpers mirror the triggers (RB / R1 FIRE, LB / L1 AIM); the d-pad
  carries the weapon cycle (left / right) and the zoom (up / down).
- Mouse look with a sensitivity setting and a separate scoped (sniper)
  sensitivity; controller look sensitivity and stick deadzones.
- Hold / Toggle for crouch and for sprint.

**Display**

- Widescreen aspect ratios (4:3 / 16:9 / 32:9), never a stretch; FOV;
  resolution (a dropdown of the measured mode table); windowed / borderless /
  fullscreen; VSync.
- The widescreen cursor repair (the game's pointer reaches the whole
  widescreen frame) and the watch pointer's visibility.

**Front end**

- Native front-end and watch SETTINGS pages, persisted in `config.ini` under
  `%LOCALAPPDATA%\sightline`.
- **4. QUIT GAME** on the main menu.

## Nothing ROM-derived ships — what changed to make that true

At v0.1.0 the executable carried 528 bytes read out of the ROM at build
time: the audio microcode's ENVMIXER ramp (16 bytes) and RESAMPLE polyphase
table (512 bytes), compiled in from a locally extracted copy of the aspMain
data segment. v0.2.0 derives both **from the player's own ROM at start-up**
(`src/platform/sl_ucode.c`: the 1172-compressed segment at ROM 0x21990 is
inflated with the game's own inflater, the 704-byte data segment is sliced
out, the two tables are read from it into memory, once, before the game
boots). What the executable embeds is two SHA-1 *digests* used to refuse a
wrong, patched or truncated ROM with a clear message — never the data, and
there is no fallback table. The build no longer needs an extracted segment or
a generated header; `tools/windows/validate-package.ps1 -Rom …` scans every
shipped file for the ROM header, the microcode data segment and the two
tables as compiled, and finds none (it finds both in a v0.1.0 build).
`tools/windows/ucodetabtest.ps1` proves the run-time tables byte-identical to
an independent standard-library derivation and proves a ROM with one changed
byte is refused.

The other non-Git input the Windows build used to depend on — the matching
build's linker map, `build/u/ge007.u.map`, which only the MIPS toolchain can
produce — is now a tracked extraction, `tools/native/ge007.u.linkmap.txt`:
symbol names and link addresses only (segment windows and the asset files'
ROM offsets, the same numbers `scripts/filelist.u.csv` carries), with its
provenance (source map SHA-256, the commit `make matching` ran at, the ROM it
reproduced as `MATCH!`) in its header. No ROM bytes, no game data.

## ROM requirement

Sightline includes no GoldenEye ROM and no game data. A user-supplied
GoldenEye 007 (USA) dump is required: a plain, uncompressed, big-endian
`.z64`, 12582912 bytes, SHA-1 `abe01e4aeb033b6c0836819f549c791b26cfde83`.
`.n64` / `.v64` dumps are byte-swapped and are refused at start-up with the
reason on the console.

## Windows support statement

Windows 10 / 11 x64, 32-bit build, OpenGL. No other platform.
