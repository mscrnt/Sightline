# data/overrides

Small hand-tuned per-level corrections to deriver output. An override file over ~30 lines means the deriver is wrong — fix the deriver.

Not to be confused with `data/asset-overrides/`, which holds committed custom
models for the boot screens (`docs/asset-overrides.md`). Different feature:
that directory holds binary `.slmodel` files measured in megabytes, this one
holds text corrections measured in lines.
